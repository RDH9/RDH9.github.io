Building a Custom IDS in Python: Detecting Port Scans and ICMP Floods

For my first serious cybersecurity project, I wanted to build something that showed real engineering, not just "installed Snort and followed a tutorial." So I built a lightweight intrusion detection system from scratch in Python using Scapy.

The lab setup

Everything runs in an isolated Proxmox network segment:

  • Windows Server VM running the IDS (Npcap + Python + Scapy)
  • Kali Linux VM as the attacker, generating real scan/flood traffic
  • Both on a dedicated internal bridge with no physical NIC, so nothing leaks onto the real network

What it detects

The first version detects three classic patterns by tracking per-source-IP behavior in sliding time windows:

  • Port scans — many distinct destination ports from one source IP within a short window (SYN packets, tracked with a deque of timestamped ports)
  • ICMP floods — high volume of ICMP echo requests from a single source in a short window
  • Repeated connection attempts — many SYNs to the same destination port, a basic brute-force signal

Validating it against real traffic

The whole point was validating detections against actual attack traffic, not just theoretical logic:

# Port scan
nmap -sS 10.10.10.10

# ICMP flood
hping3 --icmp --flood 10.10.10.10

# Repeated connection attempts
hping3 -S -p 3389 --flood 10.10.10.10

Each of these triggered the corresponding alert within a few seconds on the IDS console — a satisfying confirmation that the detection logic actually works against real traffic, not just synthetic test data.

What's next

Planned improvements: logging to file/JSON instead of just console output (needed to eventually feed a SIEM), a whitelist for known-good management IPs, and mapping each detection to its corresponding MITRE ATT&CK technique (e.g., port scanning maps to T1046) for the eventual writeup.
